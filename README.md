# Sakthi Dental Clinic — ShadowFox Internship Project

A responsive multi-page dental clinic website built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — landing page, featured treatments, amenities, testimonials and CTAs
- `about.html` — clinic story, founder profile, vision/mission and doctor team
- `treatments.html` — all 16 treatments
- `faq.html` — 14 frequently asked questions
- `contact.html` — clinic details and validated front-end contact form
- `privacy.html` — privacy policy draft for clinic review

## Run locally
1. Extract the ZIP.
2. Open the `sakthi-dental-clinic` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Keep the `css` and `js` folders in the same locations so assets load correctly.

## Deployment
### GitHub Pages
1. Create a GitHub repository and upload the contents of this folder.
2. Open **Settings → Pages**.
3. Choose the main branch and root folder, then save.
4. Wait for the deployment URL shown in the Pages section.

### Netlify
1. Sign in to Netlify and choose **Add new site → Deploy manually**.
2. Drag the extracted project folder into the deploy area.
3. Netlify will provide a public URL.

## Before production launch
- Replace the Unsplash demo images with approved clinic photographs and the supplied Drive assets.
- Confirm clinic details, opening hours, doctor credentials, testimonials, facilities and pickup/drop-off support with the client.
- Connect the contact form to a secure form backend/service. The current form validates locally and does not send or store submissions.
- Review and approve the privacy policy for the clinic's real data practices and applicable law.
- Confirm the clinic has permission to publish patient testimonials and any photos.
- Add actual social media profile URLs in place of placeholder links.
- Pricing was not supplied in the brief, so no unverified prices have been invented.

## Design notes
The visual system uses blue, white and soft pink accents, generous spacing, responsive card grids, visible calls to action, keyboard-friendly form controls and a mobile navigation menu. It uses Google Fonts and Unsplash image URLs; an internet connection is required for those remote assets.
